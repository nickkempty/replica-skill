# Highlight Shorts

เครื่องมือตัดไฮไลท์จากวิดีโอเกมเป็นคลิปสั้นแนวตั้ง (Shorts) สำหรับใช้คนเดียวบนเครื่องตัวเอง

วางลิงก์ YouTube ของวิดีโอที่คุณได้รับอนุญาตให้ใช้ โปรแกรมจะเลือกช่วงที่น่าสนใจให้เอง
คุณพากเสียงของตัวเองทับ โปรแกรมใส่ซับ แล้วอัปขึ้นช่องของคุณเป็นฉบับร่างส่วนตัว

ทุกอย่างรันบนเครื่องคุณ ไม่มีค่าบริการรายเดือน ไม่ต้องใช้ API key ของ AI

## สิ่งที่ต้องมี

- Python 3.10 ขึ้นไป
- ffmpeg (ต้องเรียกคำสั่ง `ffmpeg` และ `ffprobe` ได้จากหน้าต่างคำสั่ง)
  - Windows: `winget install Gyan.FFmpeg`
  - macOS: `brew install ffmpeg`
  - Ubuntu: `sudo apt install ffmpeg`
- ไมโครโฟนและหูฟัง

## ติดตั้ง

```bash
cd highlight-shorts
python -m venv ~/hshorts-venv
source ~/hshorts-venv/bin/activate        # Windows: %USERPROFILE%\hshorts-venv\Scripts\activate
pip install -r requirements.txt
```

## เปิดใช้

```bash
python -m hshorts
```

แล้วเปิดเบราว์เซอร์ที่ http://localhost:8000

## ขั้นตอนใช้งาน

1. **งานใหม่** วางลิงก์ YouTube (หรือที่อยู่ไฟล์ในเครื่อง) กรอกชื่อช่องต้นทาง
   แล้วติ๊กยืนยันว่าได้รับอนุญาตจากเจ้าของ ถ้าไม่ติ๊กโปรแกรมจะไม่ทำงานให้
2. **รอประมวลผล** โปรแกรมดาวน์โหลด วิเคราะห์ และเลือกไฮไลท์ วิดีโอ 1 ชั่วโมงใช้เวลาไม่กี่นาที
3. **ดูไฮไลท์** คลิปเรียงจากน่าสนใจที่สุด พร้อมเหตุผลที่เลือก ปรับจุดเริ่ม จุดจบ และกรอบภาพได้
   ไม่ชอบคลิปไหนกดเอาออก อยากได้เพิ่มกด "ขอไฮไลท์เพิ่มอีก"
4. **พากเสียง** ใส่หูฟัง กด "เริ่มอัดเสียงพาก" แล้วพูดไปพร้อมคลิป อัดใหม่ได้ไม่จำกัด
5. **ซับ** โปรแกรมถอดเสียงพากเป็นซับให้ แก้คำผิดได้
   (ครั้งแรกจะดาวน์โหลดโมเดลถอดเสียงราว 500 MB หนึ่งครั้ง)
6. **ส่งออกและอัป** กด "ส่งออกคลิป" ได้ไฟล์ mp4 ขนาด 1080x1920 แล้วกดอัปขึ้น YouTube

## โปรแกรมเลือกไฮไลท์อย่างไร

ให้คะแนนทุกวินาทีจากความดังของเสียง การพุ่งขึ้นของเสียงกะทันหัน (ระเบิด ยิงกัน เสียงตะโกน)
และความเร็วของการเคลื่อนไหวในภาพ แล้วเลือกช่วงที่คะแนนสูงสุดโดยไม่ให้ซ้อนกัน
ถ้าวิดีโอมีคนพูดเยอะ เปิด "ใช้คำพูดในวิดีโอต้นฉบับช่วยเลือกด้วย" ในตั้งค่าเพิ่มเติมได้ แต่จะช้ากว่ามาก

## เชื่อมบัญชี YouTube (ทำครั้งเดียว)

1. เข้า https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่
2. เมนู APIs & Services > Library ค้นหา "YouTube Data API v3" แล้วกด Enable
3. เมนู APIs & Services > OAuth consent screen เลือก External กรอกชื่อแอปและอีเมล
   แล้วเพิ่มอีเมล Google ของคุณในหัวข้อ Test users
4. เมนู APIs & Services > Credentials > Create credentials > OAuth client ID
   เลือกชนิด Desktop app แล้วดาวน์โหลดไฟล์ JSON
5. เปลี่ยนชื่อไฟล์เป็น `client_secret.json` แล้ววางในโฟลเดอร์ `highlight-shorts-data`
   ในโฟลเดอร์ผู้ใช้ของคุณ (โปรแกรมสร้างโฟลเดอร์นี้ให้เมื่อเปิดครั้งแรก)
6. กดปุ่ม "เชื่อมบัญชี YouTube" ที่มุมขวาบนของหน้าเว็บ แล้วลงชื่อเข้าใช้ช่องของคุณ

## ข้อจำกัดที่ควรรู้

- **อัปเป็นส่วนตัวเสมอ** คุณต้องเข้า YouTube Studio เพื่อตรวจและกดเผยแพร่เอง
  แอปที่ยังไม่ผ่านการตรวจสอบของ Google จะอัปแบบสาธารณะโดยตรงไม่ได้อยู่แล้ว
- **อัปได้ราว 6 คลิปต่อวัน** ตามโควตาเริ่มต้นของ YouTube Data API
- **ต้องพากเสียงก่อนอัป** ปุ่มอัปจะใช้ไม่ได้จนกว่าคลิปจะมีเสียงพากของคุณ
  เพราะคลิปที่ตัดมาเฉย ๆ ไม่ผ่านนโยบายสร้างรายได้ของ YouTube
- **คลิปยาวได้ไม่เกิน 60 วินาที**
- **ใช้เฉพาะวิดีโอที่ได้รับอนุญาต** โปรแกรมใส่เครดิตและลิงก์ต้นฉบับท้ายคำอธิบายให้อัตโนมัติ
  แต่การขออนุญาตเป็นความรับผิดชอบของคุณ ควรเก็บหลักฐานการอนุญาตไว้

## ตั้งค่าผ่านตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `HS_DATA` | `~/highlight-shorts-data` | โฟลเดอร์เก็บงานและคลิป |
| `HS_PORT` | `8000` | พอร์ตของหน้าเว็บ |
| `HS_WHISPER` | `small` | ขนาดโมเดลถอดเสียง (`tiny`, `base`, `small`, `medium`) |
| `HS_FONT` | `Noto Sans Thai` | ฟอนต์ของซับ ต้องเป็นฟอนต์ที่ติดตั้งในเครื่องและรองรับภาษาไทย |
