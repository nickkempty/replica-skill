# เครื่องมือตัดไฮไลท์เป็น Shorts (ชื่อชั่วคราว: highlight-shorts)

วันที่: 2026-11-15
สถานะ: รออนุมัติ

## เป้าหมายและเหตุผล

เจ้าของช่องต้องการทำคลิปสั้นแนวตั้งจากวิดีโอเกม GTA 6 บน YouTube ที่ได้รับอนุญาตให้ใช้
พากเสียงของตัวเองทับ แล้วอัปขึ้นช่อง YouTube ส่วนตัวเพื่อทำรายได้ ใช้คนเดียว บนเครื่องตัวเอง

สิ่งที่ทำให้ช่องผ่านการสร้างรายได้คือเสียงพากของเจ้าของช่อง เครื่องมือจึงต้องทำให้
ขั้นตอน "หาไฮไลท์" เป็นอัตโนมัติ และขั้นตอน "พากเสียง" ง่ายที่สุด

## สิ่งที่ต้องได้ (goals)

1. วางลิงก์ YouTube (หรือเลือกไฟล์วิดีโอในเครื่อง) แล้วโปรแกรมเลือกไฮไลท์ที่น่าสนใจให้เอง
2. ได้คลิปแนวตั้ง 1080x1920 ยาวไม่เกิน 60 วินาที
3. อัดเสียงพากผ่านไมค์ในหน้าเดียวกับที่ดูคลิป
4. มีซับไตเติลฝังในคลิป จากเสียงพากของผู้ใช้ (ไทยหรืออังกฤษ)
5. ส่งออกเป็นไฟล์ mp4 และอัปขึ้นช่อง YouTube เป็นฉบับร่างส่วนตัว

## สิ่งที่ไม่ทำ (non-goals)

- ระบบสมาชิก การชำระเงิน เซิร์ฟเวอร์ออนไลน์
- เสียงพากสังเคราะห์ด้วย AI และบทพากที่ AI เขียน
- ตั้งเวลาอัปอัตโนมัติ อัปไป TikTok หรือ Reels
- ติดตามใบหน้า ใส่เพลง ใส่เอฟเฟกต์

## สิ่งที่ถือว่าล้มเหลวแม้โปรแกรมทำงานได้ (anti-goals)

- อัปคลิปที่ยังไม่มีเสียงพากของผู้ใช้ขึ้นช่อง
- ใช้คลิปที่ผู้ใช้ไม่ได้ยืนยันว่าได้รับอนุญาต
- เผยแพร่คลิปสู่สาธารณะโดยผู้ใช้ไม่ได้ดูก่อน

## ข้อจำกัด

- รันบนเครื่องผู้ใช้ทั้งหมด ไม่มีค่าบริการรายเดือน ไม่ต้องใช้ API key ของ AI
- การอัปผ่าน YouTube Data API จากแอปที่ยังไม่ผ่านการตรวจสอบของ Google:
  คลิปถูกล็อกเป็นส่วนตัว และโควตาเริ่มต้นอัปได้ราว 6 คลิปต่อวัน
- ผู้ใช้ต้องสร้าง OAuth client ของ Google เองหนึ่งครั้ง (มีคู่มือทีละขั้นใน README)
- repo นี้มีเทสต์ห้ามใช้เครื่องหมาย em dash ในไฟล์ .md .py .json และกำหนดว่าโฟลเดอร์ที่มี
  SKILL.md ที่ราก repo ต้องมี 11 ตัวเท่าเดิม โค้ดใหม่จึงอยู่ในโฟลเดอร์ของตัวเองและไม่มี SKILL.md

## แนวทางที่พิจารณา

| แนวทาง | ข้อดี | ข้อเสีย |
| --- | --- | --- |
| A. แอปหน้าเว็บรันบนเครื่อง | ดูตัวอย่าง ปรับคลิป พากเสียง ในที่เดียว | สร้างนานที่สุด |
| B. คำสั่งบรรทัดเดียว | สร้างเร็ว | ต้องพากเสียงในโปรแกรมอื่น ไม่มีหน้าตัวอย่าง |
| C. อัตโนมัติทั้งหมดด้วยเสียง AI | ไม่ต้องทำอะไรเลย | ขัดนโยบายสร้างรายได้ของ YouTube |

ผู้ใช้เลือก A และกำหนดเพิ่มว่าโปรแกรมต้องเลือกไฮไลท์ให้เอง

## ขั้นตอนการใช้งาน

```
1. งานใหม่     วางลิงก์ + ติ๊ก "ฉันได้รับอนุญาตจากเจ้าของ" + กรอกชื่อช่องต้นทาง (ใช้เป็นเครดิต)
2. ประมวลผล    แถบความคืบหน้า: ดาวน์โหลด > วิเคราะห์ > เลือกไฮไลท์
3. ไฮไลท์      รายการคลิปที่โปรแกรมเลือกให้ เรียงตามคะแนน พร้อมเหตุผลสั้น ๆ
               [ดูตัวอย่าง] [เอาออก] [ปรับจุดเริ่ม/จบ] [ขอเพิ่มอีก]
4. พากเสียง    เล่นคลิป + กดอัด + อัดใหม่ได้ + ปรับความดังเสียงต้นฉบับ
5. ซับ         ข้อความจากเสียงพาก แก้คำผิดได้
6. ส่งออก      [บันทึกไฟล์] [อัปขึ้น YouTube เป็นฉบับร่าง] ชื่อ คำอธิบาย แท็ก แก้ได้
```

## การเลือกไฮไลท์

โปรแกรมให้คะแนนทุกวินาทีของวิดีโอจากสัญญาณ 3 อย่าง:

- ความดังของเสียงเทียบกับค่าเฉลี่ยของวิดีโอ และการพุ่งขึ้นกะทันหัน (ระเบิด ยิงกัน เสียงตะโกน)
- ความเร็วของการเปลี่ยนแปลงในภาพ (ฉากไล่ล่า การปะทะ)
- คำพูดในต้นฉบับถ้ามี: ความถี่ของคำ คำอุทาน เสียงหัวเราะ

จากนั้นหาจุดยอดของคะแนน ขยายเป็นช่วง 20 ถึง 45 วินาที (ตั้งค่าได้ สูงสุด 60)
ขยับขอบให้ตรงช่วงเงียบหรือจบประโยค ไม่ให้ช่วงซ้อนกัน แล้วเลือก 8 ช่วงคะแนนสูงสุด (ตั้งค่าได้)
แต่ละช่วงมีป้ายเหตุผล เช่น "เสียงพุ่ง + ภาพเคลื่อนไหวเร็ว"

## ภาพแนวตั้ง

ค่าเริ่มต้นคือครอปกลางจอให้เต็ม 9:16 และเลื่อนตำแหน่งซ้ายขวาได้ต่อคลิป
ทางเลือกที่สองคือวางภาพเต็มตรงกลางบนพื้นหลังเบลอ

## เสียงและซับ

- เสียงพากอัดผ่านไมค์ในเบราว์เซอร์ ยาวเท่าคลิป อัดใหม่ได้ไม่จำกัด
- เสียงต้นฉบับลดเหลือ 20% ใต้เสียงพาก (ปรับได้ 0 ถึง 100%)
- ซับถอดจากเสียงพากด้วย Whisper ที่รันบนเครื่อง แก้ข้อความได้ก่อนฝังลงคลิป

## การอัป

- เชื่อมบัญชี Google ครั้งแรกครั้งเดียว
- อัปเป็นส่วนตัวเสมอ ผู้ใช้กดเผยแพร่เองใน YouTube Studio
- คำอธิบายใส่เครดิตช่องต้นทางและลิงก์ต้นฉบับอัตโนมัติ
- ปุ่มอัปใช้ได้เมื่อคลิปมีเสียงพากแล้วเท่านั้น

## ส่วนเทคนิค (ผู้สร้างตัดสินใจ)

- Python 3.10+ กับ FastAPI หน้าเว็บเป็น HTML/JS ธรรมดา ไม่มีขั้นตอน build
- yt-dlp ดึงวิดีโอ, ffmpeg ตัด ครอป ผสมเสียง ฝังซับ, faster-whisper ถอดเสียง
- google-api-python-client สำหรับอัป
- เก็บงานเป็นโฟลเดอร์ต่องานพร้อมไฟล์ JSON ไม่มีฐานข้อมูล
- งานหนักรันเบื้องหลัง หน้าเว็บถามความคืบหน้าเป็นระยะ
- โค้ดอยู่ในโฟลเดอร์ `highlight-shorts/` ใน repo นี้ เทสต์ของมันอยู่ในโฟลเดอร์เดียวกัน
- เปิดใช้ด้วยคำสั่งเดียว แล้วเข้า http://localhost:8000

โครงสร้างโมดูล:

| โมดูล | หน้าที่ |
| --- | --- |
| `ingest` | ดาวน์โหลดจากลิงก์หรือรับไฟล์ในเครื่อง ตรวจว่าติ๊กยืนยันสิทธิ์แล้ว |
| `analyze` | สกัดสัญญาณเสียง ภาพ และคำพูด เป็นคะแนนต่อวินาที |
| `highlights` | หาจุดยอด สร้างช่วง เลือกและให้เหตุผล |
| `render` | สร้างคลิปแนวตั้ง ผสมเสียงพาก ฝังซับ |
| `subtitles` | ถอดเสียงพากและสร้างไฟล์ซับ |
| `upload` | OAuth และอัปขึ้น YouTube เป็นส่วนตัว |
| `server` + `web/` | API และหน้าเว็บ |

## การทดสอบ

- เทสต์อัตโนมัติสำหรับการให้คะแนน การสร้างช่วง และการเรนเดอร์ โดยใช้วิดีโอสังเคราะห์ที่ ffmpeg สร้างขึ้น
- ส่วนดาวน์โหลดและอัปทดสอบด้วยตัวจำลอง เพราะต้องใช้เครือข่ายและบัญชีจริง
  ผู้ใช้ต้องลองสองส่วนนี้กับบัญชีจริงบนเครื่องตัวเองหนึ่งครั้ง
- เทสต์เดิมของ repo ต้องผ่านทั้งหมดเหมือนเดิม

## สิ่งที่ปล่อยให้ผู้สร้างตัดสินใจ

- น้ำหนักของสัญญาณแต่ละตัวในสูตรคะแนน (ปรับจากการลองกับวิดีโอเกมจริง)
- หน้าตาของหน้าเว็บ ภายในขั้นตอน 6 ข้อข้างบน
- รูปแบบตัวอักษรและตำแหน่งของซับ
- ขนาดโมเดล Whisper เริ่มต้น
